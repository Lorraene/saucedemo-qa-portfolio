## Techniques applied (from the ISTQB CTFL syllabus)

- Equivalence partitioning (login credentials, checkout form fields)
- Boundary value analysis (number of items in the cart: 0, 1, maximum available)
- Exploratory testing with a written charter
- Experience-based checks on usability and compatibility (browsers and mobile viewport)

## What this project is not

- No test automation. I'm learning it and I'm not presenting it as a skill yet.
- No formal requirements exist for this demo site, so I wrote down the requirements I assumed (see the test plan). Where the site behaves differently from my assumption, I say so and explain my reasoning.
